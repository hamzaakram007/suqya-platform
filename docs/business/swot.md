# SWOT Analysis

## Strengths

- End-to-end platform: order → dispatch → POD → payment → ZATCA invoice → accounting
- Arabic-first RTL across all surfaces
- Multi-tenant SaaS (marketplace + white-label + franchise)
- B2B credit system with aging reports and statements
- Rule-based dispatch with ML upgrade path

## Weaknesses

- Cold-start problem in new cities (need supplier density)
- High integration complexity (ZATCA, payments, maps)
- Competing against established phone/WhatsApp ordering habits
- 12-month enterprise scope requires significant capital

## Opportunities

- No dominant player with full B2B credit + ERP + ZATCA in one platform
- Vision 2030 digital transformation and e-invoicing mandate
- Enterprise segment underserved (construction, hospitality, government)
- GCC expansion after Saudi product-market fit
- IoT auto-reorder and AI demand forecasting

## Threats

- NWC government utility sets price expectations
- Existing aggregators (Suqiakum, YT9, MoyaApp) with user base
- Regulatory changes (ZATCA waves, PDPL enforcement)
- Supplier disintermediation (direct WhatsApp relationships)
- Payment fraud and credit defaults
