# Critical Journeys V2

## J1 — Customer 3-tap order (returning user)

1. Open app → Map Home (address + payment + preferred tank preloaded)  
2. Tap tank chip (or keep default)  
3. Tap **تأكيد الطلب**  

System: create order → supplier review → dispatch. Navigate to Live Track.

**First-time:** after OTP, guided pin drop once; then same 3-tap forever.

## J2 — Driver offer → POD

1. Online on map  
2. Offer sheet 30s → Accept  
3. Navigate → Mark filled → Arrive → POD (photo/sign/OTP)  
4. Cash collect if needed → back to online  

## J3 — Supplier accept

1. Today → new order card  
2. Accept → auto dispatch visible on fleet map  

## J4 — Admin intervene

1. Live Ops sees stuck order (red pin)  
2. Exceptions rail → reassign / call
